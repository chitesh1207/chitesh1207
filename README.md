## 🚀 Featured Project

### Smart Warehouse IT Infrastructure Lab

I independently designed and built a simulated warehouse IT environment to develop practical skills relevant to warehouse IT support.

| Area | What I implemented |
|---|---|
| **Identity and access** | Windows Server 2022, Active Directory, organisational units, users, security groups and password policies |
| **Core infrastructure** | DNS, DHCP, domain services and Windows 10 domain-joined client configuration |
| **Group Policy** | Drive mapping, printer deployment and automated 7-Zip software deployment |
| **File services** | SMB shares, NTFS permissions and group-based access control |
| **Warehouse devices** | Simulated label-printer and scanner-support scenarios |
| **Networking** | Multiple subnets, VLAN simulation, RRAS routing, firewall rules and port testing |
| **Automation** | PowerShell validation, software inventory and troubleshooting commands |
| **Database** | SQL Server 2022 Express, remote SSMS administration, sample warehouse database, backup and restore testing |
| **Support process** | Incident documentation, root-cause analysis, validation and recovery snapshots |

### Key troubleshooting scenarios

- Label printer unavailable because the Print Spooler service stopped
- Scanner-share access denied because of incorrect group permissions
- Warehouse VLAN routing and firewall access testing
- Group Policy software deployment verification
- SQL Server remote-connectivity, port, certificate and authentication troubleshooting
- Database backup and restore validation

> Repository and complete documentation are being prepared for publication.
